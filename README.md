# 🍽️ Laziz Restaurant - Full Stack Food Ordering Website

A modern, fully responsive full-stack food ordering web application built using the MERN Stack. Users can browse delicious meals, place orders, manage their cart, and enjoy a smooth restaurant ordering experience across all devices.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/Laziz-Restaurant.git
```

---

## Install Frontend

```bash
cd client
npm install
npm run dev
```

---

## Install Backend

```bash
cd server
npm install
npm start
```

---

# 🔐 Environment Variables

Create a `.env` file inside the **server** folder.

```env
PORT=5000

MONGODB_URI=Your_MongoDB_URI

JWT_SECRET=Your_JWT_Secret

CLOUDINARY_CLOUD_NAME=Your_Cloud_Name

CLOUDINARY_API_KEY=Your_API_Key

CLOUDINARY_API_SECRET=Your_API_Secret
```
